# IMU Motion Dataset Tool

Desktop application written in Qt 5.12 for collecting, visualizing and editing motion datasets from ESP32-based IMU devices.

## Features

- Live visualization (QCustomPlot)
- Serial communication
- BLE GATT support (planned)
- Motion session recording
- CSV export
- Dataset editing

## Stack

- C++
- Qt 5.12
- QCustomPlot
- SQLite
